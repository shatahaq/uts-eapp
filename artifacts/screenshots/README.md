# Screenshot Medan Smart Tourism

48 screenshot PNG asli, resolusi 1080 × 2400 piksel.

Buka index.html untuk galeri. Klik setiap gambar untuk melihat ukuran penuh. Halaman panjang disertakan dalam beberapa posisi scroll.

Akun, pemesanan, pembayaran, dan antrean menggunakan data demo. Pengambilan gambar tidak mengubah kode aplikasi.
